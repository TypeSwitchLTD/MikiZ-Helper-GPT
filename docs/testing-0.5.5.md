# Mission Control 0.5.5 — בדיקות קצרות

## התקנה
1. `npm.cmd run typecheck` עובר.
2. `npm.cmd run build` עובר.
3. `npm.cmd run dev` פותח את האפליקציה.

## ElevenLabs
4. הגדרות > פתיחת בוקר וקול > בחר ElevenLabs.
5. הזן API Key + Voice ID ושמור.
6. לחץ "בדוק קול". צריך לשמוע משפט קצר או לקבל שגיאה ברורה.
7. לחץ Play במסך הראשי. אם ElevenLabs תקין, הוא צריך לנגן אודיו אמיתי ולא קול דפדפן.
8. אם חסר Voice ID/API Key, ההודעה צריכה להסביר בדיוק מה חסר.

## פתיחת בוקר ומזג אוויר
9. נאום הבוקר כולל מזג אוויר בוקר/צהריים.
10. ביום רגיל מוצגת שקיעה; ביום שישי כניסת שבת; בשבת צאת שבת.
11. תאריך עברי מוצג באותיות.

## תוכנית יום
12. כפתור "תוכנית יום" נפתח.
13. מופיע בלוק "אימון בוקר".
14. אפשר לערוך שעה/כותרת/פירוט לכל בלוק.
15. "אשר ושמור תוכנית יום" שומר תוכנית ומסמן משימות חשובות לבוקר.

## דוח / ייבוא
16. אין טאב דוח / ייבוא בראש.
17. הדוח/ייבוא נמצא בתוך הגדרות.
18. ייבוא Daily Report עדיין עובד משם.

## Add Task
19. הכנסת משימה עדיין עובדת.
20. "סדר לי טיוטה" לא מאבד שורות.
