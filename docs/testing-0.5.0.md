# Mission Control 0.5.0 - בדיקות סופיות לפייז הזה

## התקנה
1. `npm.cmd run typecheck` עובר ללא שגיאות.
2. `npm.cmd run build` עובר ללא שגיאות.
3. `npm.cmd run dev` פותח את האפליקציה ב־http://127.0.0.1:5173.

## עיצוב ופריסה
4. הרקע תכלת עדין ולא כחול מדי גם בגלילה למטה.
5. פאנל המידע יושב בצד ימין בדסקטופ.
6. הגרסה מופיעה פעם אחת בלבד בפאנל הצד.
7. החיפוש והטאבים לא חופפים לתוכן.
8. כפתור הפליי ליד Mission Control נראה ברור.

## פתיחת בוקר מדברת
9. לחיצה על Play פותחת חלון "פתיחת בוקר מדברת".
10. לחיצה על "הקריא" מפעילה הקראה דרך הדפדפן.
11. לחיצה על "עצור" מפסיקה את ההקראה.
12. "ייצא נאום" מוריד קובץ Markdown.
13. הטקסט מזכיר מספר משימות היום, משימות בתהליך, לידים ותזכורות מקומיות.

## משימות
14. פתיחה/סגירה של כרטיס משימה עובדת.
15. Start / Done בתתי־משימות עובדים ונשמרים אחרי Refresh.
16. משימה שהושלמה עדיין ניתנת לביטול סימון.
17. הוספת תת־משימה למשימת־על קיימת עובדת.

## הכנסת משימה
18. כפתור + נשאר באמצע.
19. "סדר לי טיוטה" פותח Review Sectors.
20. Review לא מאבד שורות גם אם שורה הוגדרה בטעות כמשימה קיימת בלי יעד.
21. שמירה לפי שיוך יוצרת משימות חדשות וממזגת תתי־משימות קיימות.
22. אין dropdowns קריטיים במסך Review; הבחירות החשובות הן בקליק.

## דאטה
23. "ייצא Daily State לבדיקה" מוריד JSON.
24. אחרי Refresh המשימות וההגדרות נשמרות.
25. אין שגיאות Console אדומות בשימוש רגיל.
