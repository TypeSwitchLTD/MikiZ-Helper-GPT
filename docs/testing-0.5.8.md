# Mission Control 0.5.8 — בדיקות

## לפני עדכון
1. פתח את הגרסה שעבדה היום.
2. לחץ `ייצא Daily State לבדיקה` ושמור את הקובץ בצד.
3. אל תמחק Browser Data / Site Data / IndexedDB.
4. המשך לעבוד על אותו origin: `http://127.0.0.1:5173`.

## בדיקות חובה
1. האפליקציה נטענת בלי שגיאת IndexedDB objectStore.
2. המשימות מהיום עדיין קיימות.
3. הטאבים החדשים הם: משימות / סושיאל / אימונים / הגדרות.
4. בטאב משימות מופיע פילטר `כל מה שרלוונטי` מעל `היום`.
5. `כל מה שרלוונטי` מציג משימות להיום, בתהליך, תזכורות, השבוע הקרוב ובאקלוג חשוב.
6. המספור ליד המשימות מופיע.
7. החיפוש מוצא משימות.
8. החיפוש מוצא גם הגדרות ומציג אותן עם ⚙ וצבע שונה.
9. לחיצה על תוצאת הגדרה עוברת להגדרות.
10. תזכורת קיימת מופיעה בסימון 🔔 על המשימה/תת־משימה.
11. הוספת תזכורת חדשה שומרת ומופיעה בפאנל הצד.
12. כשהזמן מגיע והאפליקציה פתוחה, מופיע toast + Notification אם כרום מאושר.
13. טיימר פוקוס נפתח מהפאנל.
14. טיימר פוקוס סופר לאחור, מצלצל ומציג הודעה בסיום.
15. Daily State עדיין יורד.
16. ייצוא דוח לייבוא מחר עדיין יורד.
17. ElevenLabs עדיין עובד אם ההגדרות קיימות.
18. Add Task / Review עדיין שומר בלי לאבד שורות.
19. Start / Done עדיין עובדים.
20. החצים לסידור פוקוס עדיין עובדים.
