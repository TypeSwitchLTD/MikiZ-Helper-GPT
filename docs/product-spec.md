# Mission Control — Product Notes

This project is a local-first personal operating cockpit, not a SaaS product.

Phase 0 + Phase 1 scope only:

1. Project foundation.
2. RTL/Hebrew app shell.
3. Dexie/IndexedDB schema.
4. Domain types.
5. Settings defaults.
6. Seed import.
7. Basic local data services.
8. Read-only UI verification.

Future phases are intentionally deferred.
