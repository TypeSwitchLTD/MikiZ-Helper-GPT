# Mission Control 0.5.9 — בדיקות קצרות

## לפני עדכון
1. בגרסה העובדת כרגע לחץ ייצא Daily State לבדיקה ושמור את ה־JSON בצד.
2. אל תמחק Browser Data / Site Data / IndexedDB.
3. המשך להיכנס דרך http://127.0.0.1:5173 ולא localhost.

## אחרי עדכון
1. npm.cmd run typecheck עובר.
2. npm.cmd run build עובר.
3. אין שגיאת IndexedDB objectStore was not found.
4. המשימות מהיום עדיין מופיעות.
5. בטאב משימות יש דרופבוקס פילטר אחד ולא שורת בועות ארוכה.
6. פתיחת הדרופבוקס מציגה: כל מה שרלוונטי, היום, קלילים, באקלוג, חוזר/שבועי, גמורות, מבוטלות.
7. בחירה מסומנת במסגרת שחורה ברורה.
8. הוספת משימה > סדר לי טיוטה נראה פחות צפוף.
9. אם אין התאמת משימת־על קיימת מופיעה ההודעה: לא נמצאו משימות־על מתאימות.
10. תגיות מהירות מופיעות מתחת להודעה הזאת.
11. שמירה מתוך Review לא מאבדת שורות.
12. חיפוש עדיין מוצא משימות והגדרות.
