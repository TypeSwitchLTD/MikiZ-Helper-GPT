# Mission Control 0.5.4 — QA checklist

## התקנה
1. `npm.cmd run typecheck` עובר.
2. `npm.cmd run build` עובר.
3. `npm.cmd run dev` פותח את האפליקציה.

## מזג אוויר / שקיעה / שבת
4. בפאנל Mission Control מופיע מזג אוויר אמיתי או fallback ברור.
5. ביום רגיל מוצגת שעת שקיעה.
6. ביום שישי מוצגת כניסת שבת אם Hebcal מחזיר נתון.
7. ביום שבת מוצגת צאת שבת אם Hebcal מחזיר נתון.
8. בנאום הבוקר מופיע מזג אוויר בוקר/צהריים לפי העיר בהגדרות.

## תאריך עברי
9. בנאום הבוקר התאריך העברי מוצג כולו באותיות, למשל `כ״ג באייר תשפ״ו`.
10. ב־Ready for Morning מוצג תאריך עברי באותיות.

## Morning Command Center
11. כפתור `תוכנית יום` נפתח.
12. מוצגות עד 3 משימות חשובות.
13. מוצגות עד 2 פתיחות קלות.
14. מוצגת משימה שלא כדאי לדחות.
15. מוצגים בלוקים מוצעים ליום.

## ElevenLabs / Voice
16. אם ElevenLabs נבחר אבל חסר Voice ID, מופיעה הודעה ברורה.
17. אם ElevenLabs נבחר אבל חסר API Key/Proxy, מופיעה הודעה ברורה.
18. אם ElevenLabs לא מוגדר, קול דפדפן עדיין עובד כ־fallback.

## Social prep
19. בהגדרות יש אזור חיבורים לרשתות חברתיות.
20. אפשר לסמן LinkedIn פעיל ולשמור URL/token placeholder.
21. אפשר לסמן Instagram פעיל ולשמור username/token placeholder.
22. אחרי Refresh ההגדרות נשמרות.

## Add Task / Review
23. Review עדיין נפתח אחרי `סדר לי טיוטה`.
24. שורות Review לא נעלמות בשמירה.
25. אזורי תגיות/פרויקט/תחום קומפקטיים יותר.
