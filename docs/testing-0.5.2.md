# Mission Control 0.5.2 — QA checklist

## התקנה
1. `npm.cmd run typecheck` עובר.
2. `npm.cmd run build` עובר.
3. `npm.cmd run dev` פותח את האפליקציה.

## Layout / Scroll
4. הרקע הפנימי של Mission Control כמעט לבן.
5. הפאנל הימני לבן ונקי.
6. בדסקטופ יש גלילה נפרדת לפאנל הצד וללוח המשימות.
7. גלילה בלוח המשימות לא מושכת את הפאנל הימני.
8. אם הפאנל הימני ארוך, הוא גולל בפני עצמו.

## Morning Briefing
9. Play פותח את חלון פתיחת הבוקר.
10. התאריך העברי מוצג עם שנה במספרים, למשל 5786.
11. מופיעה בחירת קול הקראה.
12. בחירת קול אחר נשמרת אחרי סגירה ופתיחה.
13. הקריא עובד.
14. עצור עובד.
15. ייצא נאום מוריד Markdown.

## Add Task / Review
16. החלק העליון של "סדר לי טיוטה" נראה נקי ולא כמו כפתור תקוע.
17. סדר לי טיוטה פותח Review.
18. Review לא מאבד שורות.
19. שמירה עובדת.
20. Daily State Export עדיין עובד.
