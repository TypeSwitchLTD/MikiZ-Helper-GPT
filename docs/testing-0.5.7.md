# Mission Control 0.5.7 — Search, Handoff, Safe Update

## בדיקות חובה
1. חיפוש מוצא גם משימה שהושלמה.
2. לחיצה על תוצאת חיפוש של משימה גמורה פותחת את הטאב המתאים ומדגישה את הכרטיס.
3. במסך הכנסת משימה, תגיות/פרויקט/תחום לא דוחסים את כל הסקטור.
4. אם אין התאמה למשימת־על קיימת, מופיע הטקסט: לא נמצאו משימות־על מתאימות.
5. כפתור ייצא דוח לייבוא מחר מוריד קובץ Markdown.
6. כפתור Daily State עדיין מוריד JSON מלא.
7. אחרי עדכון גרסה, המשימות הקיימות לא נמחקות.
8. בדוק typecheck ו-build.

## שמירת מידע
הגרסה לא משנה את שם IndexedDB ולא מוחקת טבלאות. בנוסף נוצרת snapshot מקומית אוטומטית בפעם הראשונה שהגרסה נפתחת.
