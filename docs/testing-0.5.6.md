# Mission Control 0.5.6 — Focus Order + Reminders

## לפני עדכון חשוב
1. פתח את הגרסה הקיימת.
2. לחץ `ייצא Daily State לבדיקה` ושמור את קובץ ה־JSON במקום בטוח.
3. אל תמחק נתוני אתר / Browser storage / IndexedDB.
4. החלף את קבצי הפרויקט בלבד. הנתונים שלך נשארים בדפדפן.

## בדיקות התקנה
1. `npm.cmd run typecheck` עובר.
2. `npm.cmd run build` עובר.
3. `npm.cmd run dev` פותח את האפליקציה.
4. הנתונים מהיום עדיין מופיעים אחרי העדכון.

## Focus Order
1. במסך היום מופיעים 4 כפתורי חצים ליד הסטטוס/עדיפות/מאמץ.
2. `⇧` מעלה את המשימה לראש הרשימה.
3. `↑` מעלה מקום אחד.
4. `↓` מוריד מקום אחד.
5. `⇩` שולח לתחתית רשימת היום, אחרי משימות שכבר נדחו קודם.
6. רענון הדף שומר את הסדר.
7. הסדר משנה רק את תצוגת היום, לא את העדיפות האמיתית.

## עריכה
1. פתח משימה > שינוי משימה > עריכת מלל.
2. שנה טקסט ולחץ `ביטול עריכה` — הערכים חוזרים למה שהיה.
3. עריכת פרטים כוללת `ביטול פרטים`.
4. הוספת תת־משימה כוללת `ביטול`.

## תזכורות
1. פתח משימה > שינוי משימה > הוסף תזכורת.
2. בחר היום/מחר/תאריך ושעה.
3. שמור תזכורת.
4. התזכורת מופיעה בפאנל Mission Control תחת תזכורות פעילות.
5. אפשר להוסיף תזכורת גם לתת־משימה מתוך שורת התת־משימה.
6. אם הדפדפן מבקש הרשאת Notifications — אשר.
7. כשהאפליקציה פתוחה והגיע זמן התזכורת, אמורה להופיע התראת דפדפן.

## גבולות ידועים
- התראות מקומיות עובדות כשהאפליקציה פתוחה בדפדפן.
- Push אמיתי כשהאפליקציה סגורה דורש Service Worker + שרת/Proxy + VAPID, וזה נשמר לשלב הבא.
- ElevenLabs נשאר כמו ב־0.5.5, כולל Model ID תקין כמו `eleven_v3` או `eleven_multilingual_v2`.
